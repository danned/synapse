# Run Mutators

**Focus:** Replayability

## Current friction

Difficulty modes primarily change intel and build timing. Experienced players have few ways to seek a distinctly different run once they know the core rules.

## Idea

Add optional, clearly described mutators at run start. Examples include slower but stronger pulses, lower starting charge with larger wave rewards, or more fast enemies. Show active mutators in the HUD and include them with the seed on the results screen so a challenge can be replayed accurately.

## Why it helps

Mutators create new network-design problems without replacing the existing easy, normal, and hardcore modes.
