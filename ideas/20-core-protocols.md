# Core Protocols

**Focus:** Run identity

## Opportunity

Mutators alter rules and loadouts choose tower types, but the Core always launches pulses in the same basic pattern.

## Idea

Before a run, choose one Core protocol with a visible tradeoff. **Tempo** launches smaller, faster pulses; **Reservoir** stores a pulse during quiet moments and releases it into the next occupied lane; **Stability** launches slower pulses but shortens link disable time. Show the selected protocol on the Core and in the results screen. Leave the default protocol available for a familiar baseline.

## Why it helps

The choice changes how every branch feels and rewards different network shapes from the opening build onward. It gives runs a strong identity without adding another tower.

## Design check

Define pulse size in existing damage terms, cap stored pulses, and verify each protocol has a viable route through all five levels and difficulties.
