# Variable Board Layouts

**Focus:** Replayability and strategy

## Current friction

Runs vary by enemy manifest and mutation draft, but the two paths and blocked cells are fixed. Familiar placements can solve the same geometry repeatedly.

## Idea

Create a small set of hand-checked path and scar-tissue layouts. Select one from the run seed and preview it before the player commits to a build. Each layout should preserve two readable lanes, a reachable Core, and viable early tower placements.

## Why it helps

Players must adapt network geometry without facing unfair or impossible maps. Seeded selection keeps runs reproducible and shareable.
