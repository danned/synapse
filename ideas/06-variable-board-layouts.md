# Variable Board Layouts

**Focus:** Replayability and strategy

## Current friction

The campaign now has a distinct path and blocked-cell layout for each level. Within a level, every run still uses the same geometry, so familiar placements can solve it repeatedly.

## Idea

Create a small set of hand-checked path and scar-tissue variants for each level. Select a variant from the run seed and preview it before the player commits to a build. Each variant should preserve two readable lanes, a reachable Core, and viable early tower placements.

## Why it helps

Players must adapt network geometry without facing unfair or impossible maps. Seeded selection keeps runs reproducible and shareable.
