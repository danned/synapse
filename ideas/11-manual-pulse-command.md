# Manual Pulse Command

**Focus:** Combat agency

## Opportunity

Once a wave starts, a well-built network is mostly watched rather than played. A single timed intervention could make a close defense feel earned.

## Idea

Let the player tap a built node and spend charge to launch one extra pulse down its existing route during combat. Show the route and arrival time before confirmation. Give the command a short cooldown and a rising cost for repeated uses within the same wave; reset that cost after the wave. It cannot create links or bypass disabled ones.

## Why it helps

The player can rescue a threatened lane through timing, while spending charge that would otherwise fund the next build. The network still determines what the command can accomplish.

## Design check

Keep it optional on Easy and useful but limited on Hardcore. Test that repeated commands cannot replace good topology or trivialize a boss.
