# Signal Combos

**Focus:** Network synergy

## Opportunity

Tower types have distinct attacks, but most combinations are simply more damage or more slowing. Pulse timing could create satisfying interactions between branches.

## Idea

Add a small, discoverable set of two-type combos triggered when different tower arrivals hit the same enemy within a brief window. For example, Cryo then Lance could pierce a frozen target and its neighbor; Arc then Rift could cause the field to discharge once. Show a two-icon cue on the enemy and a distinct effect when the combo fires. Cap each combo per enemy so fast pulse builds remain balanced.

## Why it helps

Players would design for both geometry and arrival order. A clever network could outperform a more expensive pile of the same tower.

## Design check

Start with two combos whose outcomes are visibly different from existing status effects. Explain them in tower details and avoid making any one combo mandatory.
